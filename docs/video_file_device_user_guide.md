# 视频文件虚拟设备功能使用指南

## 功能概述

视频文件虚拟设备功能允许将本地视频文件作为一个虚拟监控设备添加到系统中，用于测试和演示目的。添加的设备默认状态为在线，可以在任务配置中选择作为检测源。

---

## 功能特点

### ✅ 核心特性
- **虚拟监控设备**：视频文件作为虚拟设备添加到摄像机管理列表
- **默认在线状态**：设备添加后默认为在线状态，可直接使用
- **支持多种格式**：MP4、AVI、MKV、MOV等常见视频格式
- **文件管理**：视频文件保存在服务器专用目录中
- **目录分组**：支持将设备分配到不同的目录进行管理

### 📋 设备信息
添加的视频文件设备将包含以下标识信息：
- **协议**：`file`（文件类型）
- **制造商**：`Video File`
- **型号**：`Virtual Device`
- **取流地址**：`file://<文件路径>`

---

## 使用方法

### 1. 打开视频文件上传界面

1. 访问流媒体管理页面：`http://localhost:5555/cameras`
2. 点击页面右上角的"**添加视频文件**"按钮

### 2. 选择视频文件

在弹出的模态框中：
- **点击"浏览..."按钮**选择本地视频文件
- 支持格式：MP4、AVI、MKV、MOV等
- 选择文件后，设备名称会自动生成（可修改）

### 3. 填写设备信息

必填字段：
- **设备名称**：虚拟设备的显示名称（如："测试视频-入口监控"）

可选字段：
- **设备描述**：设备的描述信息
- **所属目录**：将设备分配到特定目录

### 4. 添加设备

点击"**添加设备**"按钮，系统将：
- 保存视频文件到服务器（`uploads/video_files/`目录）
- 创建虚拟设备记录
- 设备状态设置为"在线"
- 自动刷新摄像机列表

## 注意事项

### ⚠️ 文件大小限制
- 默认限制：16MB（Flask默认配置）
- 大文件上传需调整Flask配置：`MAX_CONTENT_LENGTH`

### ⚠️ 文件格式支持
- 建议使用标准编码格式（H.264/H.265）
- 避免使用特殊编码或加密视频

### ⚠️ 存储空间
- 视频文件保存在服务器本地
- 定期清理不需要的视频文件，释放磁盘空间

### ⚠️ 性能考虑
- 视频文件作为本地文件读取，不受网络带宽限制
- 检测性能取决于视频分辨率和帧率

## 常见问题

### Q1: 上传失败怎么办？
**A**: 检查以下内容：
- 视频文件格式是否支持
- 文件大小是否超过限制
- 服务器存储空间是否充足

### Q2: 如何区分真实设备和虚拟设备？
**A**: 查看"制造商"和"型号"字段：
- 虚拟设备：制造商=Video File，型号=Virtual Device
- 真实设备：显示实际厂商信息

### Q3: 可以修改已上传的视频文件吗？
**A**: 不支持直接修改。如需更换视频，请：
1. 删除原虚拟设备
2. 重新添加新的视频文件
