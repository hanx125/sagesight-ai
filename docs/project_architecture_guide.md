# SageSight-AI 项目架构全景图

## 🎯 核心模块详解

### 1. 视频解码模块 (src/decoders/)

**核心类**：`VideoDecoder`

**功能**：
- FFmpeg 硬件加速解码（DXVA2/CUDA/VAAPI/Vulkan）
- 共享内存环形缓冲区（零拷贝帧传输）
- 帧索引队列（解耦生产者和消费者）
- 支持多种视频源（RTSP/文件/摄像头）

**关键参数**：
```python
VideoDecoder(
    video_file="rtsp://...",      # 视频源
    hwaccel_preset="preset-dxva2", # 硬件加速预设
    width=640,                    # 输出宽度
    height=640,                   # 输出高度
    ring_buffer_block_count=3     # 环形缓冲区块数
)
```

**性能特性**：
- 帧传输延迟：< 5ms（零拷贝）
- 内存占用：低（固定块数）
- CPU 占用：低（硬件加速）

---

### 2. 运动检测模块 (src/motion/)

**核心类**：`MotionDetector`

**功能**：
- MOG2 背景建模（自适应阈值）
- 运动区域提取（前景掩码）
- 运动历史记录（辅助重识别）
- 置信度调整（融合检测结果）

**关键参数**：
```python
MotionDetector(
    history=500,              # 背景建模历史帧数
    var_threshold=16.0,       # 方差阈值（越小越敏感）
    detect_shadows=False,     # 是否检测阴影
    min_area=500,             # 最小运动区域面积
    confidence_boost=0.15,    # 置信度增益
    confidence_penalty=0.05   # 置信度惩罚
)
```

**使用场景**：
- ✅ 固定摄像头（背景相对稳定）
- ✅ 室外场景（光照变化）
- ✅ 室内场景（人员流动）
- ❌ 移动摄像头（背景不断变化）
- ❌ 快速光照变化（如闪光灯）

**输出**：
```python
MotionRegion(
    bbox=(x1, y1, x2, y2),  # 运动区域边界框
    area=1000,              # 区域面积（像素）
    center=(cx, cy),        # 中心点
    intensity=0.8           # 运动强度（0-1）
)
```

---

### 3. 目标检测模块 (src/detectors/)

**核心类**：
- `BaseDetector`（检测器基类）
- `ONNXCUDADetector`（ONNX Runtime 检测器）
- `TensorRTDetector`（TensorRT 检测器）
- `RKNNDetector`（RKNN 检测器）
- `DetectionProcessPool`（检测进程池）

**检测进程池特性**：
- 多进程并行检测（充分利用 GPU）
- GPU 利用率：80-95%（比传统方式 +50%）
- 进程级隔离（崩溃不影响其他进程）
- 检测队列（异步任务分发）

**关键参数**：
```python
DetectionProcessPool(
    num_detectors=2,              # 检测进程数量
    detector_config={...},        # 检测器配置
    detection_queue_maxsize=100   # 队列容量
)
```

**性能对比**：

| 方式 | GPU 利用率 | FPS（多摄像机） | 延迟 |
|------|-----------|----------------|------|
| 传统单线程 | 40-60% | 5-8 | 100-200ms |
| 检测进程池 | **80-95%** | **10-15** | **80-150ms** |

---

### 4. 目标跟踪模块 (src/tracking/)

**核心类**：`BoTSORTTracker`

**算法**：BoT-SORT（ByteTrack + OC-SORT + ReID）

**核心特性**：
- 三阶段匹配（IoU + ReID + 运动预测）
- Kalman 滤波（轨迹平滑）
- ReID 特征提取（外观相似度）
- 运动历史记录（辅助重识别）

**关键参数**：
```python
BoTSORTTracker(
    track_thresh=0.5,    # 跟踪阈值
    track_buffer=30,     # 跟踪缓冲帧数
    match_thresh=0.8,    # 匹配阈值
    frame_rate=30        # 帧率
)
```

**输出**：
```python
Track(
    track_id=1,                    # 跟踪 ID
    bbox=[x1, y1, x2, y2],         # 边界框
    confidence=0.85,               # 置信度
    class_id=1                     # 类别 ID
)
```

---

### 5. 事件输出模块 (src/events/)

**核心类**：`EventOutput`

**功能**：
- 轨迹管理（开始/更新/结束）
- GIF 生成（目标片段）
- 多通道输出（MQTT/WebSocket/FTP/MinIO）

**关键方法**：
```python
EventOutput(
    mqtt_config={...},     # MQTT 配置
    websocket_config={...}, # WebSocket 配置
    ftp_config={...}       # FTP 配置
)

# 发送事件
emit_event(event_type, data)
```

## 🔧 故障排查

### 常见问题

#### 1. CUDA EP 未激活
**现象**：`[警告] CUDA EP 未激活！实际使用：['CPUExecutionProvider']`

**原因**：CUDA 版本不匹配

**解决**：
- 安装 CUDA 13.* 和 cuDNN 9.*
- 或使用 `backend='onnx_cpu'`

#### 2. 帧索引为空
**现象**：`get_frame_index()` 返回 None

**原因**：解码器未启动或缓冲区为空

**解决**：
- 检查视频源是否有效
- 增加等待时间（`time.sleep(2.0)`）

#### 3. 运动检测误报
**现象**：静止场景检测到运动

**原因**：参数不匹配场景

**解决**：
- 增加 `var_threshold`（降低灵敏度）
- 增加 `min_area`（过滤小区域）
- 增加 `history`（提高背景稳定性）
