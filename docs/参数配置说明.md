## 1. 解码器参数

**来源**: `src/decoders/video_decoder.py` - `DecoderConfig`

### 1.1 必填参数

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `rtsp_url` | str | RTSP 流地址 | "" | 有效 RTSP URL（如: `rtsp://192.168.1.100:554/stream1`） |
| `video_file` | str | 视频文件路径 | "" | 本地视频文件路径（如: `test_videos/test.mp4`） |

**注意**: `rtsp_url` 和 `video_file` 二选一，至少提供一个。

### 1.2 视频解码参数

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `width` | int | 解码输出宽度 | 640 | 320-1920（建议: 640, 1280） |
| `height` | int | 解码输出高度 | 640 | 320-1080（建议: 640, 720） |
| `hwaccel` | str | 硬件加速方式 | "dxva2" | `dxva2`（Windows）/ `cuda`（NVIDIA）/ `qsv`（Intel）/ `none`（软解码） |
| `rtsp_transport` | str | RTSP 传输协议 | "tcp" | `tcp`（稳定）/ `udp`（低延迟） |
| `reconnect` | bool | 是否自动重连 | True | true/false |
| `reconnect_delay` | int | 重连延迟（秒） | 5 | 1-60 秒 |
| `buffer_size` | int | 输入缓冲区大小（字节） | 1048576 | 512KB-10MB（建议: 1MB） |
| `frame_queue_size` | int | 帧队列大小 | 30 | 5-100 帧 |


### 1.3 参数说明

#### width & height
- **作用**: 控制解码输出的分辨率
- **建议**: 
  - RTX 2070 GPU: 使用 `640x640`（平衡性能和精度）
  - 高性能 GPU: 使用 `1280x720`（更高精度）
- **限制**: 必须满足 YUV420p 格式要求（高度为偶数）

#### hwaccel（硬件加速）
- **dxva2**: Windows Direct-X Video Acceleration（推荐 Windows 用户）
- **cuda**: NVIDIA CUDA 硬件加速（需要 NVIDIA GPU）
- **qsv**: Intel Quick Sync Video（需要 Intel CPU）
- **none**: 纯软件解码（CPU 占用高，不建议）

#### rtsp_transport
- **tcp**: 传输稳定，适合网络不稳定场景
- **udp**: 传输延迟低，适合局域网稳定场景

#### reconnect
- **true**: RTSP 流断开后自动重连（推荐）
- **false**: 不重连，任务失败后需手动重启

## 2. 预处理参数

**来源**: `src/detectors/preprocessor.py` - `OptimizedPreprocessor`

### 2.1 基础参数

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `width` | int | 输入图像宽度 | 640 | 必须与解码器 `width` 一致 |
| `height` | int | 输入图像高度 | 640 | 必须与解码器 `height` 一致 |
| `model_input_size` | int | YOLO 模型输入尺寸 | 640 | 640（YOLOv8n/YOLO11n），必须与检测器 `input_width/height` 一致 |
| `rgb_mean` | tuple | RGB 均值（归一化） | (0.0, 0.0, 0.0) | 通常为 0（YOLO 模型） |
| `rgb_std` | tuple | RGB 标准差（归一化） | (1.0, 1.0, 1.0) | 通常为 1（YOLO 模型） |

### 2.2 处理流程

1. **YUV420p → RGB**:
   - U/V 上采样到完整分辨率
   - YUV 三通道合并
   - OpenCV 颜色转换

2. **Resize（如果需要）**:
   - 将 RGB 图像 resize 到 `model_input_size`（如: 640x640）
   - 使用 `cv2.INTER_LINEAR` 插值

3. **归一化**:
   - RGB 像素值从 `[0, 255]` 归一化到 `[0, 1]`
   - 应用自定义归一化：`(pixel / 255 - rgb_mean) / rgb_std`
   - 默认：`rgb_mean=(0,0,0)`, `rgb_std=(1,1,1)` → 结果等同于 `pixel / 255`

4. **HWC → CHW**:
   - 从 `(Height, Width, Channel)` 转换为 `(Channel, Height, Width)`
   - 添加 batch 维度: `(1, 3, H, W)`

### 2.3 性能优化

- **YUV → RGB**: 平均耗时约 **2-3ms**
- **归一化 + CHW**: 平均耗时约 **0.5ms**
- **总耗时**: 约 **3-5ms**
- **理论 FPS**: 200-300 FPS

## 3. 检测器参数

**来源**: `src/detectors/yolo_detector.py` - `DetectorConfig`

### 3.1 模型配置

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `model_path` | str | ONNX 模型路径 | "" | 相对路径（如: `models/yolov11n.onnx`） |
| `model_type` | str | 模型类型 | "yolov8n" | `yolov8n` / `yolo11n` |
| `class_names` | Tuple[str] | 类别名称列表 | COCO 80 类 | 从算法库标签文件动态加载 |

### 3.2 推理后端配置

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `backend` | str | 推理后端类型 | "onnx_tensorrt" | `onnx_cuda` / `onnx_tensorrt` / `tensorrt` |
| `use_fp16` | bool | 使用 FP16 精度 | True | true/false（仅 TensorRT） |
| `tensorrt_engine_cache_path` | str | TensorRT Engine 缓存路径 | "./trt_cache" | 本地目录路径 |
| `tensorrt_engine_path` | str | TensorRT Engine 文件路径 | "" | backend="tensorrt" 时使用（如: `models/yolov11n_trt_fp16.engine`） |
| `tensorrt_lib_path` | str | TensorRT lib 目录路径 | "" | Windows 需要配置（如: `D:\TensorRT-10.5.0.18\lib`） |

#### backend（推理后端）

- **onnx_cuda**: ONNX Runtime + CUDA Execution Provider（兼容性最好）
- **onnx_tensorrt**: ONNX Runtime + TensorRT Execution Provider（自动转换，推荐）
- **tensorrt**: 直接加载 TensorRT Engine（性能最优，需手动生成 Engine）

#### tensorrt_lib_path 说明

- **作用**: 指定 TensorRT 动态库路径（Windows 需要配置）
- **优先级**: 配置参数 > 环境变量 `TENSORRT_LIB_PATH` > 硬编码默认路径
- **建议**: 如果已配置系统环境变量，则不需要设置此参数

### 3.3 推理参数

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `conf_threshold` | float | 置信度阈值 | 0.25 | 0.1-0.9（建议: 0.25-0.5） |
| `iou_threshold` | float | NMS IoU 阈值 | 0.45 | 0.3-0.7（建议: 0.45） |
| `min_box_area` | float | 最小检测框面积（像素） | 10.0 | 10-500（建议: 50） |

### 3.4 GPU 配置

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `device_id` | int | GPU 设备 ID | 0 | 0（单 GPU）/ 1（多 GPU） |
| `gpu_mem_limit` | int | GPU 显存限制（字节） | 6442450944 | 2GB-8GB（RTX 2070: 6GB） |

### 3.5 输入配置

| 参数名 | 类型 | 说明 | 默认值 | 取值范围/限制 |
|--------|------|------|--------|--------------|
| `input_width` | int | 输入宽度 | 640 | 必须与 `model_input_size` 一致 |
| `input_height` | int | 输入高度 | 640 | 必须与 `model_input_size` 一致 |

### 3.6 性能参考（RTX 2070 GPU）

| 后端 | FP16 | 平均推理时间 | FPS |
|------|------|--------------|-----|
| onnx_cuda | False | 15-20ms | 50-65 FPS |
| onnx_tensorrt | True | 10-15ms | 65-100 FPS |
| tensorrt | True | 8-12ms | 80-120 FPS |

|--------|------|------|--------|--------------|
| `history` | int | 背景建模历史帧数 | 500 | 100-1000（建议: 300-500） |
| `var_threshold` | float | 方差阈值 | 16.0 | 4-64（越小越敏感） |

|--------|------|------|--------|--------------|
| `min_area` | int | 最小运动区域面积（像素） | 500 | 100-2000（过滤噪声） |
| `blur_size` | int | 模糊核大小（降噪） | 5 | 3-15（必须为奇数） |
| `morph_size` | int | 形态学核大小（填充空洞） | 5 | 3-15（必须为奇数） |

### 4.5 适用场景

**适用场景**:
- 固定摄像头（背景相对稳定）
- 室外场景（光照变化）
- 室内场景（人员流动）

**不适用场景**:
- 移动摄像头（背景不断变化）
- 快速光照变化（如闪光灯）

## 8. 配置优先级说明

### 8.1 配置层级

系统采用三层配置优先级机制：

```
代码默认值 < 配置文件默认值 < 任务管理配置
```

**优先级规则**:
- **最高优先级**: 任务管理中的用户配置（前端表单）
- **中等优先级**: 配置文件中的默认值（如果任务管理未配置）
- **最低优先级**: 代码中的硬编码默认值（兜底）

### 8.2 配置流程

1. **任务创建**:
   - 前端表单收集用户配置
   - 未填写字段使用 `DEFAULT_*_CONFIG` 默认值
   - 保存到数据库 `tasks` 表

2. **任务执行**:
   - 从数据库读取任务配置
   - 解析 JSON 配置字段（如: `decoder_config`, `detector_config`）
   - 创建配置对象（如: `DecoderConfig`, `DetectorConfig`）
   - 初始化各模块（解码器、检测器、跟踪器等）

3. **参数传递**:
   ```python
   # 示例：检测器配置传递
   detector_config = DetectorConfig(
       model_path=task.model_path,
       conf_threshold=task.conf_threshold,
       iou_threshold=task.detector_config.get('iou_threshold', 0.45),
       backend=task.detector_config.get('backend', 'onnx_tensorrt'),
       use_fp16=task.detector_config.get('use_fp16', True),
       ...
   )
   ```

### 8.3 前端表单字段映射

**任务管理页面字段** → **数据库字段** → **代码参数**

| 前端字段 | 数据库字段 | 代码参数 | 所属模块 |
|----------|-----------|---------|---------|
| RTSP 地址 | `rtsp_url` (task表) | `DecoderConfig.rtsp_url` | 解码器 |
| 模型路径 | `model_path` | `DetectorConfig.model_path` | 检测器 |
| 目标类别 | `target_classes` | `DetectorConfig.class_names` | 检测器 |
| 置信度阈值 | `conf_threshold` | `DetectorConfig.conf_threshold` | 检测器 |
| NMS 阈值 | `nms_threshold` | `DetectorConfig.iou_threshold` | 检测器 |
| GPU 设备 | `detector_config.device_id` | `DetectorConfig.device_id` | 检测器 |
| 跟踪阈值 | `tracker_config.track_thresh` | `BoTSORTTracker.track_thresh` | 跟踪器 |
| 运动检测 | `motion_config.enabled` | `MotionDetector.enabled` | 运动检测 |
