# 事件清理功能增强方案

## Context（背景）

当前事件清理功能存在严重缺陷：
- **[task_manager.py:1391-1404](file:///e:/sagesight-ai/src/tasks/task_manager.py#L1391-L1404)** 的 `clear_old_events()` 只删除数据库记录，**完全不删除存储文件**
- **[event_output.py:613-665](file:///e:/sagesight-ai/src/events/event_output.py#L613-L665)** 的 `_cleanup_old_images()` 只清理本地图片，不清理GIF、FTP、MinIO
- **[ftp_outputter.py](file:///e:/sagesight-ai/src/events/ftp_outputter.py)** 和 **[minio_outputter.py](file:///e:/sagesight-ai/src/events/minio_outputter.py)** 都只有 upload 方法，**没有 delete 方法**
- 没有自动清理定时任务
- 前端 [events.html:249-280](file:///e:/sagesight-ai/templates/events.html#L249-L280) 只有手动清理，无法配置自动清理

数据库 `events` 表已有6个存储URL字段（local/minio/ftp × image/gif），但清理时完全没用上。

**目标：**
1. 事件清理时同时清理存储对象（图片/GIF文件）
2. 本地、FTP、MinIO 三种存储类型一并清理
3. 前端可自定义自动清理的时间（保留天数、清理间隔、启用开关）

```python
    """事件清理服务 - 统一清理数据库记录和存储对象"""

    def cleanup_events_by_days(self, days: int) -> dict:

        # 1. 查询过期事件（含6个URL字段）
        # 2. 逐个事件调用 _cleanup_event_storage() 删除文件
        # 3. 删除数据库记录
        # 4. 返回统计 {deleted_records, deleted_files, failed_files}

    def _cleanup_event_storage(self, event) -> dict:
        """删除单个事件的6个存储对象"""
        # 解析并删除：local_image_url, minio_image_url, ftp_image_url
        #           local_gif_url, minio_gif_url, ftp_gif_url

    def _delete_local_file(self, url: str) -> bool:
        """从URL提取本地路径并删除（去掉 http://host:port/ 前缀）"""

    def _delete_minio_object(self, url: str) -> bool:
        """从URL提取object_name并删除"""

    def _delete_ftp_file(self, url: str) -> bool:
        """从URL提取filename并删除"""
```

**URL解析策略：**
- 本地URL格式：`http://host:port/output/images/{event_id}.jpg` → 提取 `output/images/{event_id}.jpg`
- MinIO URL格式：presigned URL → URL解码后取path最后一段作为object_name
- FTP URL格式：`ftp://user:pass@host:port/{remote_dir}/{filename}` → 取path最后一段作为filename

**复用现有资源：**
- FTP/MinIO 配置从 [system_config_loader.py](file:///e:/sagesight-ai/src/system/system_config_loader.py) 的 `load_system_config()` 读取（与 EventOutput 初始化使用相同的配置源）

### 5. 添加自动清理后台线程

**[run.py](file:///e:/sagesight-ai/run.py)** 启动时启动后台清理线程：

```python
def start_event_cleanup_scheduler():
    """启动事件自动清理后台线程"""
    import threading, time
    from src.system.system_config_loader import load_system_config
    from src.events.event_cleanup_service import EventCleanupService

    def cleanup_loop():
        while True:
            try:
                config = load_system_config()
                cleanup_cfg = config.get('event_cleanup', {})
                if cleanup_cfg.get('enabled', False):
                    days = cleanup_cfg.get('retention_days', 30)
                    interval = cleanup_cfg.get('cleanup_interval_hours', 24)
                    EventCleanupService().cleanup_events_by_days(days)
                    time.sleep(interval * 3600)
                else:
                    time.sleep(3600)  # 未启用时每小时检查一次配置
            except Exception as e:
                logger.error(f"自动清理失败: {e}")
                time.sleep(3600)

    thread = threading.Thread(target=cleanup_loop, daemon=True, name='event-cleanup')
    thread.start()
```
